# Census Flow V5 — Photo, responsivité et identité visuelle naturelle

## Web
- Import d’image depuis l’appareil.
- Capture directe avec aperçu vidéo via la caméra du navigateur.
- Reprise et suppression de la photo avant enregistrement.
- Compression automatique des images.
- Interface de capture plein écran sur mobile.
- Ajustements responsive des modales, formulaires, barres de recherche et tableaux.
- Animations discrètes avec respect de `prefers-reduced-motion`.
- Palette naturelle : vert forêt, sauge, terre et argile.

## Mobile
- Deux actions explicites : caméra et galerie.
- Autorisations distinctes caméra / photothèque.
- Compression via Expo Image Picker et conservation locale Base64.
- Aperçu, reprise de photo et animation entre étapes.
- Disposition adaptée aux petits écrans.
- Palette claire et sombre harmonisée avec le web.

Aucune migration de base de données n’est requise.
