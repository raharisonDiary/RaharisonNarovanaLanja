# Census Flow V6.5 — Saisie mobile des ménages

## Objectif

Aligner la gestion mobile des ménages sur le fonctionnement de la version web, sans supprimer la collecte complète hors ligne déjà disponible.

## Nouvelle saisie de ménage

Un nouvel écran mobile `households/create` permet désormais de :

1. sélectionner une campagne active ;
2. rechercher et sélectionner une habitation créée au préalable ;
3. visualiser la référence, le fokontany et les coordonnées de l’habitation ;
4. utiliser une référence ménage générée automatiquement ;
5. choisir le type de ménage ;
6. saisir le chef de ménage et son téléphone ;
7. enregistrer le ménage dans l’API principale.

Après l’enregistrement, l’application demande immédiatement si l’agent souhaite ajouter un citoyen dans ce ménage.

## Liaison avec les citoyens

- l’écran Citoyens affiche maintenant une section dédiée au ménage avant les informations personnelles ;
- le ménage peut être recherché et sélectionné ;
- un bouton permet de créer un ménage lorsqu’il n’existe pas encore ;
- après création d’un ménage, le formulaire citoyen s’ouvre automatiquement avec le bon ménage déjà sélectionné ;
- depuis la liste des ménages, l’action « Ajouter un citoyen » ouvre directement le formulaire concerné.

## Gestion des ménages

La page mobile Ménages propose maintenant deux actions clairement séparées :

- **Saisir un ménage** : fonctionnement identique à la version web, à partir d’une habitation existante ;
- **Collecte complète hors ligne** : ancien parcours terrain regroupant habitation, ménage et citoyens dans une file locale.

Les ménages locaux conservent également une action directe pour ajouter un citoyen avant synchronisation.

## Données

Aucune migration PostgreSQL, donnée géographique, variable `.env`, dépendance npm ou donnée locale existante n’est modifiée.
