# Census Flow V6.7

## Verification des doublons citoyens

La verification est appliquee a tous les parcours de saisie :

- application mobile connectee ;
- collecte mobile hors ligne dans un menage ;
- Expo Web ;
- application Web principale ;
- API backend, afin d'eviter les doublons provenant de deux appareils differents.

Les controles utilisent :

1. le numero CIN lorsqu'il est renseigne ;
2. le nom et les prenoms ;
3. la date de naissance exacte ou l'annee ;
4. sinon l'age et le lieu de naissance ;
5. le menage et la campagne pour limiter les faux positifs.

La modification d'un citoyen exclut correctement l'enregistrement en cours du controle.

## Confirmation d'enregistrement

Apres la creation d'un citoyen :

- une notification de succes s'affiche ;
- l'utilisateur peut terminer ;
- ou ajouter immediatement une autre personne dans le meme menage.

Apres une modification, une notification confirme egalement l'enregistrement.

## Donnees

Aucune migration de base de donnees n'est requise. Les donnees, comptes, campagnes, zones administratives et fichiers `.env` ne sont pas modifies.
