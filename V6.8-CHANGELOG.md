# Census Flow V6.8 - Envoi automatique des identifiants et OTP prive

## Comptes agent et chef regional

- L'adresse e-mail devient obligatoire, car elle sert d'identifiant et de canal de livraison.
- Un seul bouton cree le compte et declenche automatiquement les deux envois :
  - e-mail SMTP ;
  - WhatsApp Cloud API.
- Le mot de passe temporaire n'est plus affiche lorsque les deux envois sont confirmes.
- Si un canal n'est pas configure ou echoue, l'ecran affiche le statut et fournit un mot de passe de secours a l'administrateur autorise afin d'eviter de perdre l'acces au compte cree.
- Le web et le mobile utilisent le meme parcours.

## Mot de passe oublie

- L'utilisateur saisit son e-mail de connexion.
- Il choisit le canal de reception : E-mail ou WhatsApp.
- Le code OTP est transmis au canal choisi.
- Le code OTP n'est plus renvoye par l'API, ni affiche dans le web, Expo Web ou l'application mobile.
- Le code OTP n'est pas ecrit dans les journaux quand les notifications sont desactivees.
- Les limites d'expiration et de tentatives restent appliquees.

## Configuration requise

L'envoi reel necessite une configuration SMTP et Meta WhatsApp Cloud API dans le fichier `.env`.

### SMTP

```env
PASSWORD_RECOVERY_EMAIL_ENABLED=true
PASSWORD_RECOVERY_EMAIL_HOST=smtp.votre-fournisseur.com
PASSWORD_RECOVERY_EMAIL_PORT=587
PASSWORD_RECOVERY_EMAIL_ENABLE_SSL=true
PASSWORD_RECOVERY_EMAIL_USERNAME=votre-utilisateur
PASSWORD_RECOVERY_EMAIL_PASSWORD=votre-mot-de-passe-ou-cle-app
PASSWORD_RECOVERY_EMAIL_FROM_ADDRESS=no-reply@votre-domaine.com
PASSWORD_RECOVERY_EMAIL_FROM_NAME=Census Flow
```

### WhatsApp Cloud API

```env
WHATSAPP_ENABLED=true
WHATSAPP_GRAPH_API_VERSION=v24.0
WHATSAPP_PHONE_NUMBER_ID=
WHATSAPP_ACCESS_TOKEN=
WHATSAPP_TEMPLATE_NAME=identifiants_census_flow
WHATSAPP_TEMPLATE_LANGUAGE=fr
WHATSAPP_OTP_TEMPLATE_NAME=otp_census_flow
WHATSAPP_OTP_TEMPLATE_LANGUAGE=fr
```

Le modele d'identifiants attend trois variables dans cet ordre : nom complet, identifiant, mot de passe temporaire.
Le modele OTP attend trois variables : nom complet, code OTP, heure d'expiration.

## Donnees

- Aucune migration PostgreSQL.
- Aucun compte, campagne, territoire ou brouillon local n'est supprime.
- Le fichier `.env` existant n'est pas remplace par l'installateur.
