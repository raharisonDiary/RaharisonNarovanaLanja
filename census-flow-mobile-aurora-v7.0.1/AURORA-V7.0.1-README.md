# Census Flow Mobile - Aurora Civic V7.0.1

Correctif du design Aurora Civic V7.0 pour Expo 57 / TypeScript.

## Installation

```powershell
Set-Location D:\projetmemoFF-complet
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\census-flow-mobile-aurora-v7.0.1\install-aurora-v7.0.1.ps1
```

## Demarrage

```powershell
Set-Location D:\projetmemoFF-complet\mobile
npx expo start -c
```

## Restauration

```powershell
Set-Location D:\projetmemoFF-complet
.\census-flow-mobile-aurora-v7.0.1\uninstall-aurora-v7.0.1.ps1
```
