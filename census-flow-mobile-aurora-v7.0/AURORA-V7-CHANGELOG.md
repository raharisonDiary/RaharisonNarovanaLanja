# Aurora Civic V7.0

Date : 3 août 2026

## Design

- système visuel Aurora Civic aligné sur la plateforme web ;
- cartes blanches, bordures fines, ombres douces et rayons généreux ;
- gradients bleu–indigo–teal ;
- hiérarchie typographique renforcée ;
- boutons tactiles de 52 px minimum ;
- navigation flottante ;
- états succès, erreur, attente et synchronisation plus lisibles ;
- écran de collecte guidée et questionnaire citoyen harmonisés ;
- nouvelles ressources d’icône et de splash.

## Sécurité fonctionnelle

Aucun fichier backend, web, PostgreSQL ou `.env` n’est inclus dans le correctif.
L’installateur crée une sauvegarde avant remplacement et restaure automatiquement les fichiers si le typecheck échoue.
