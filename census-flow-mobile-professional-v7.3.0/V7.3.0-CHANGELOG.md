# Census Flow Mobile - Professional UI V7.3.0

## Corrections principales

- Contraste sombre corrige sur l'ensemble des ecrans Expo Web.
- Les couleurs des anciens StyleSheet utilisent maintenant des variables semantiques qui changent instantanement avec le theme.
- Suppression des regles CSS fragiles qui pouvaient changer un fond sans changer le texte.
- Gradients SVG rendus fiables sur Web avec identifiants uniques et couleur de secours.
- Carte Profil entierement lisible en clair et en sombre.
- Sidebar conservee sur toutes les pages protegees, y compris Campagnes, Citoyens, Habitations, Rapports, Utilisateurs et Audit.
- Navigation principale remplace la page courante au lieu d'empiler des pages, ce qui evite les clics qui semblent bloques.
- Etat actif du menu calcule a partir des segments Expo Router.
- Sidebar entierement defilable sur les ecrans de faible hauteur : aucun module n'est cache.
- Modes Clair, Sombre et Auto synchronises avec le navigateur et le systeme.

## Ce qui n'est pas modifie

- API et appels HTTP
- Base PostgreSQL
- Authentification et OTP
- Formulaires et validations metier
- Synchronisation hors ligne
- Variables `.env`
