# Census Flow V6.6 — saisie guidée des citoyens sur mobile

## Objectif

Aligner l’enregistrement d’un citoyen sur mobile avec l’assistant de saisie disponible sur le web, sans modifier PostgreSQL, les campagnes, les comptes ou les données locales déjà enregistrées.

## Parcours mobile en six questions

1. Ménage et photo du citoyen.
2. Identité : nom, prénoms, sexe et lieu de naissance.
3. Naissance et âge : date exacte, année seulement, âge déclaré ou âge inconnu.
4. CIN : majeur avec CIN, majeur sans CIN, ou étape automatiquement ignorée pour un mineur.
5. Situation familiale, nombre d’enfants conditionnel et lien avec le chef de ménage.
6. Profession, téléphone, nationalité et vérification finale.

## Règles obligatoires et facultatives

### Obligatoires

- ménage ;
- photo ;
- nom ;
- prénoms ;
- sexe ;
- lieu de naissance ;
- information d’âge valide ;
- numéro CIN uniquement lorsque le majeur déclare posséder une CIN ;
- nombre d’enfants uniquement pour les personnes mariées ou veuves ;
- situation familiale ;
- lien avec le chef de ménage ;
- profession.

### Facultatifs

- date de délivrance de la CIN ;
- lieu de délivrance de la CIN ;
- téléphone personnel ;
- nationalité, avec « Malagasy » proposé par défaut.

## Autres corrections

- ajout du mode « année de naissance seulement » sur le formulaire mobile en ligne ;
- filtrage automatique majeur/mineur ;
- possibilité d’enregistrer un majeur sans CIN ;
- suppression ou reprise de la photo avant validation ;
- résumé final avant l’enregistrement ;
- question après sauvegarde pour ajouter immédiatement une autre personne dans le même ménage ;
- même parcours détaillé pour la collecte complète hors ligne ;
- ajout du libellé « Nationalité » en français, malagasy et anglais.
