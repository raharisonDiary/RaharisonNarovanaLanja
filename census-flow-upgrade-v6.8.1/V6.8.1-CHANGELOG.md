# Census Flow V6.8.1 - Connexion API Web et mobile

Ce correctif separe les adresses API selon la plateforme :

- Expo Web utilise `http://localhost:5001/api/v1` ;
- Expo Go, Android et iOS utilisent l'adresse IPv4 locale du PC ;
- `start-mobile.ps1` detecte automatiquement cette adresse a chaque lancement ;
- Kestrel ecoute sur `0.0.0.0:5001` pour accepter les connexions du telephone ;
- la redirection HTTP vers le certificat HTTPS local est desactivee uniquement en developpement.

Aucune base de donnees, migration ou donnee metier n'est modifiee.
