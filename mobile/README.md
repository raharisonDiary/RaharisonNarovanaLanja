# Application mobile de collecte

```bash
cp .env.example .env
npm install --legacy-peer-deps
npm start
```

Sur un téléphone physique, remplacer l’IP de l’exemple par l’IP locale du PC qui exécute l’API.

- routes : `app/`
- SQLite et SecureStore : `src/storage/`
- synchronisation : `src/sync/`
- styles : `src/styles/`
- animations : `src/animations/`
