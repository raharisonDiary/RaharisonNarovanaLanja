# Données géographiques de Madagascar

Le script `../import-madagascar-geography.ps1` télécharge, lors de son exécution, les fichiers JSON du dépôt public `julkwel/madagascar-map` : régions, districts, communes et fokontany.

Les données ne sont pas recopiées dans le projet afin de garder l’archive légère et de permettre une actualisation de la source. Le dépôt source est distribué sous licence MIT.
